Project Overview:
Cashevide API is an open-source initiative built to ensure payment security and client transparency for freelancers. Powered by Python and the Django REST Framework, it provides a robust backend system for managing freelance operations securely and efficiently.

Key Features:

    User Authentication & Management: Secure, multi-platform JWT-based login and profile management.

    Transparent Review System: Allows users to post and manage reviews for business clients using pre-defined tags, helping the freelancer community make informed decisions.

    Client Management: A dedicated space to add, edit, and track personal clients used for generating invoices.

    Service & Product Catalog: Enables users to maintain a catalog of their products or services with usage limit tracking.

    Advanced Invoicing System: Complete workflow to generate invoices, add specific invoice items, and track payment records and due balances.

    Scalable Cloud Integrations: Utilizes Redis for efficient caching, AWS SES for reliable email delivery, and Cloudflare R2 / AWS S3 for secure media storage.

    PDF Generation Ready: Configured with WeasyPrint to easily generate and export professional invoices.
